# Shiny Dashboard Demo

This part contians the scripts for Shiny Dashboard Demo

## Prerequisites
* R (>= 3.3.3)
* data.table (>= 1.10.4-3)
* dplyr (>= 0.7.1)
* DT (>= 0.2)
* ggplot2 (>= 2.2.1)
* lubridate (>= 1.7.1)
* optparse (>= 1.4.4)
* shiny (>= 1.0.5)
* shinydashboard (>= 0.6.1)
* shinyjs (>= 0.9.1)

## List of scripts

* [[server.R](./server.R)] - Shiny server script (currently available for Bauhaus and 7Fans).
* [[ui.R](./ui.R)] - Shiny UI script.
* [[runShinyApp.R](./runShinyApp.R)] - Startup script to run the shiny application.
