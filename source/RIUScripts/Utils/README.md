# Utilities for data pre-processing or other shared functions

This part contians the utilities for data pre-processing or other shared function.

## Prerequisites
* R (>= 3.3.3)
* data.table (>= 1.10.4-3)
* dplyr (>= 0.7.1)
* lubridate (>= 1.7.1)

## List of scripts

* [[master.R](./master.R)] - Utilities for all business units (BU).
* [[bauhaus.R](./bauhaus.R)] - Utilities for Bauhaus.
* [[sevenFans.R](./sevenFans.R)] - Utilities for 7Fans.
